# Privacy Policy

**Last updated: 27 September 2026**

Daily Job Intelligence Automation is a personal-use project operated by the account
owner.

## Gmail Data

The application uses read-only Gmail access solely to identify and process JobsDB job
alert emails for the account owner. It does not send, delete, modify, forward, or mark
emails as read.

## Use of Data

Job information extracted from matching alert emails is used only to produce a private
WhatsApp job report for the account owner. Gmail data is not sold, used for advertising,
used to build marketing profiles, or shared with unrelated third parties.

## Data Storage and Security

OAuth credentials and service credentials are stored as encrypted GitHub Actions
repository secrets. They are not committed to the source-code repository. A limited
history of previously reported job links may be stored to prevent duplicate reports.

## Access Control

The application requests only the Gmail read-only scope:

`https://www.googleapis.com/auth/gmail.readonly`

The account owner may revoke access at any time from the Google Account security and
third-party connections settings.
