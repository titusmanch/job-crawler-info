# Privacy Policy

Job Crawler is a personal-use automation tool.

The application uses read-only access to Gmail solely to identify and process JobsDB job alert emails for the account owner. It does not send, delete, modify, or mark emails as read.

Job information extracted from matching emails is used only to create a private WhatsApp job report. Gmail data is not sold, shared with advertisers, or provided to unrelated third parties.

OAuth credentials are stored securely as encrypted GitHub Actions secrets. The user may revoke access at any time through their Google Account security settings.
